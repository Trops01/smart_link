# Smart Link

A project created during a hackathon using React (Vite) and Node.js.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Trops01/smart_link.git
   ```

2. Navigate to the project directory:
   ```bash
   cd smart_link
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
